# SDP Tool

React/Vite starting point for the Self Development Plan tool.

## Run locally

```powershell
npm install
npm run dev
```

## Source files

- `src/legacy.html` contains the existing page markup.
- `src/styles.css` contains the extracted page styles.
- `src/legacy.js` contains the existing page behavior.

This keeps the current tool runnable while leaving room to refactor it into React components incrementally.
